## Setup Instructions

### Requirements

- C++ compiler (g++, clang, MSVC)
- Git
- Text editor or IDE (VS Code recommended)

### Building and Running

To compile a program:

```bash
g++ -o output_name src/filename.cpp
```

To run:

```bash
./output_name
```
